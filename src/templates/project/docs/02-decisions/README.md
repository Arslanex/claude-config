# Decisions

**Purpose:** Architecture Decision Records: why we chose X over Y.

**What goes here:** One ADR per decision. Never rewrite history: supersede with a new ADR and move the old one to `99-archive/`.

**File naming:** `<ID>-<kebab-title>.md` for generated docs (e.g. `ADR-0001-example-title.md`); lowercase kebab-case otherwise.

**ID prefix:** `ADR-NNNN`

Create docs with `python3 tools/docs.py new <kind> "<title>"`, not by hand.
