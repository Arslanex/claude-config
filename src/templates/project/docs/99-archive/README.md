# Archive

**Purpose:** Superseded or finished docs kept for history.

**What goes here:** Move a doc here when its status becomes `superseded` or `archived`; do not delete.

**File naming:** `<ID>-<kebab-title>.md` for generated docs (e.g. `overview-example-title.md`); lowercase kebab-case otherwise.

**ID prefix:** keeps the original ID

Create docs with `python3 tools/docs.py new <kind> "<title>"`, not by hand.
