# Domains

**Purpose:** Business rules and vocabulary, grouped by domain.

**What goes here:** One subfolder per domain (e.g. `billing/`) holding its `DOM-*` docs.

**File naming:** `<ID>-<kebab-title>.md` for generated docs (e.g. `DOM-0001-example-title.md`); lowercase kebab-case otherwise.

**ID prefix:** `DOM-NNNN`

Create docs with `python3 tools/docs.py new <kind> "<title>"`, not by hand.
