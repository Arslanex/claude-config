# Work

**Purpose:** Day-to-day work tracking: tasks, plans, handoffs and logs.

**What goes here:** `tasks/`, `plans/`, `handoffs/`, `log/`; create files with `python3 tools/docs.py new`.

**File naming:** `<ID>-<kebab-title>.md` for generated docs (e.g. `T-0001-example-title.md`); lowercase kebab-case otherwise.

**ID prefix:** `T-NNNN`, `PLAN-NNNN`, `HO-NNNN`, `LOG-NNNN`

Create docs with `python3 tools/docs.py new <kind> "<title>"`, not by hand.
